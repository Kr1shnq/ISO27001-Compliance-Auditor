How it works

  1. Collect — run Collect-ISOTelemetry.ps1 as Administrator on the target Windows host. It performs a read-only inventory and writes JSON and CSV.
  2. Assess — the engine evaluates the telemetry against all 93 Annex A:2022 controls and assigns a risk level to every gap.
  3. Attest — answer the procedural controls that cannot be measured from a machine.
  4. Export — download a management-ready PDF audit report.
